# Question 3: Four-Input Minority Function

## Objective

Implement a four-input minority function in Verilog using structural logic gates and verify it with a testbench.

## Function

The output Y is 1 when the number of input signals equal to 1 is less than the number of input signals equal to 0.

For four inputs A, B, C and D:

- Y = 1 when there are zero or one inputs equal to 1.
- Y = 0 when there are two, three or four inputs equal to 1.

## Project Structure

- `rtl/minority_function.v` — structural Verilog implementation.
- `tests/tb_minority_function.v` — testbench for all 16 input combinations.
- `Makefile` — compiles and runs the simulation.
- `run_sim.py` — checks the simulation log for successful results.
- `minority_function.vcd` — waveform data generated by the simulation.
- `simulation.log` — simulation output and test results.
